# Guide d'installation — pour les agents Zéro Perte

But : en **45 minutes**, la boutique vend avec Zéro Perte, le patron sait se servir de son tableau, et
chaque vendeur a son code. Ce guide sert **sur place** et **à distance** (appel WhatsApp).

> Règle d'or : **on ne demande jamais un mot de passe ni un code secret**. Le patron tape lui-même son code
> de 6 chiffres ; chaque vendeur reçoit le sien de l'application.

## 0. Avant de partir (ou avant l'appel)
- [ ] Le **code d'activation** de la boutique est prêt (voir `4-procedure-codes.md`), envoyé au patron sur
      WhatsApp **le jour même** (il le copiera).
- [ ] Le patron sait : le **nom exact** de la boutique, son **numéro WhatsApp**, sa ville et son quartier.
- [ ] Il a sous la main ses **20 à 50 produits les plus vendus** avec leurs prix (un cahier suffit).
- [ ] Téléphone : Android 8 ou plus, **services Google** présents, **300 Mo libres**, batterie > 50 %,
      Internet (données ou Wi-Fi) pour l'activation et le téléchargement.
- [ ] PC (si la boutique en a un) : Windows 10 ou 11, 200 Mo libres.

## 1. Installer
**Téléphone Android**
1. Ouvrir dans Chrome : `https://github.com/ahiankonoujoseph102-wq/zero-perte/releases/latest/download/ZeroPerte.apk`
2. Ouvrir le fichier téléchargé. Si Android le demande : **Paramètres → Autoriser cette source** → retour →
   **Installer**.
3. Ouvrir **Zéro Perte**.

**PC Windows**
1. Télécharger `…/releases/latest/download/ZeroPerte-Windows.zip`, clic droit → **Extraire tout**.
2. Ouvrir `zero_perte.exe`. Si « Windows a protégé votre ordinateur » : **Informations complémentaires →
   Exécuter quand même** (voir partie D de `etapes-proprietaire.md`).

## 2. Le démarrage (0.36 : 3 étapes, sans inventaire — 10 minutes)
Le patron tient le téléphone, l'agent guide (bouton **Écouter** pour entendre l'explication) :
1. **Bienvenue** → **Commencer**. *(Pour montrer d'abord l'intérêt : la vidéo de l'écran, voir
   `argumentaire-recruteurs.md`.)*
2. **Vérification du téléphone** : n'apparaît que s'il y a un problème bloquant (pas de services Google,
   moins de 100 Mo libres). → voir FAQ.
3. **Activation** : le patron ouvre WhatsApp, appuie longtemps sur le message du code → **Copier** →
   revient dans Zéro Perte → **Coller le code**. « Code accepté » → suite.
4. **Étape 1 sur 3 — le nom** de la boutique (photo facultative).
5. **Étape 2 sur 3 — deux questions** à gros boutons : « Vous vendez : **au détail / en gros / les deux** » et
   « Qui vend : **moi / un vendeur / plusieurs vendeurs** ». Ça règle l'application (boutons « Gros », vendeur
   mis en avant) ; modifiable ensuite dans **Gestion → Ma boutique**.
6. **Étape 3 sur 3 — le code du patron** : il choisit **seul** 6 chiffres, les tape deux fois. L'agent regarde
   ailleurs.
7. **« Vous pouvez vendre ! »** → **Commencer**.

**Pas d'inventaire au démarrage.** Faites tout de suite une vraie vente : **Vendre** → **Nouveau produit** →
nom + prix (et « Vendu aussi en gros » : carton de 24 à 12 000 F, par exemple) → **Ajouter et vendre** →
**Encaisser**. Un produit jamais compté affiche « pas encore compté » : aucune fausse alerte.

Le reste se fait **quand le patron a le temps**, depuis la carte **« À faire quand vous avez le temps »** de
l'accueil : compter le stock petit à petit (les produits les plus vendus d'abord), ajouter le vendeur, relier
le compte Google (sauvegarde), ajouter les prix d'achat (pour voir le bénéfice), le numéro sur les reçus.
Ce qui était avant dans l'installation (type de boutique, contact, couleur, reçu, produits connus) est dans
**Gestion → Ma boutique**.

## 3. Montrer « Produits et prix » au patron
Gestion → **Produits et prix** : ajouter un produit (nom, prix au détail, prix d'achat), et sa **vente en
gros** (nom libre : carton, sac, casier, bidon… ; combien d'unités dedans ; prix de gros ; prix **revendeur**
facultatif). Un commerçant qui vend **seulement en gros** choisit « carton » (ou sac…) comme unité.

## 3 bis. Ajouter les vendeurs (QR code, comme WhatsApp Web) — version 0.35 et plus
Il faut **Internet sur les 2 téléphones** et le compte Google de la boutique déjà relié sur le téléphone du
patron (Gestion → **Compte Google**). **Aucun compte Google ni mot de passe** sur le téléphone du vendeur.

**Sur le téléphone du patron**
1. Accueil → gros bouton **Ajouter mon vendeur** (ou Gestion → **Ajouter mon vendeur**).
2. Taper le **prénom** du vendeur → **Continuer**.
3. Google s'ouvre : choisir le **compte de la boutique**, puis **Continuer** (un seul toucher, pas de mot de
   passe).
4. Un **QR code** s'affiche. Il marche **10 minutes** et **une seule fois**.

**Sur le téléphone du vendeur**
1. Installer Zéro Perte (même lien qu'au point 1) et l'ouvrir.
2. Toucher le bouton vert **Je suis vendeur** → **Scanner le QR code** → viser le QR du patron.
3. La boutique se télécharge (environ 1 minute). Le **code secret à 4 chiffres** du vendeur s'affiche :
   **lui seul** le regarde et l'apprend. → **J'ai retenu mon code** → il tape son code : il peut vendre.
4. Sur le téléphone du patron : **« Téléphone de … ajouté »** → **Terminé**.

**Pas d'appareil photo** (ou le scan ne marche pas, téléphone sans services Google, PC) : sous le QR,
toucher **Pas d'appareil photo ?** → 8 chiffres s'affichent. Sur le téléphone du vendeur : **Je suis
vendeur** → **Pas d'appareil photo ?** → taper les 8 chiffres → **Valider**. Le téléphone du patron demande
alors « Un téléphone veut entrer : Tecno Spark 7… » → vérifier que c'est bien le téléphone **posé devant
vous** → **OUI**.

**Messages possibles**
- « La licence permet 2 appareils et ils sont déjà tous utilisés » → Gestion → **Mes appareils** → retirer
  un ancien appareil, ou vendre un **appareil en plus** (`4-procedure-codes.md`).
- « Ce QR code a expiré ou a déjà servi » → sur le téléphone du patron : **Refaire un QR code**.
- « Le relais n'est pas encore prêt » → prévenir l'assistance (réglage à faire par le propriétaire).

**Un vendeur qui partage le téléphone du patron** (pas de téléphone à lui) : Gestion → **Vendeurs** →
**Ajouter un vendeur** → prénom → l'application tire un code → le montrer au vendeur seul.

**Retirer un téléphone** (vendeur parti, téléphone perdu) : Gestion → **Mes appareils** → **Retirer**.
Téléphone **volé** ou doute : **Couper tous les vendeurs** (il faudra refaire un QR pour chacun).

**Ancien parcours** (compte Google sur chaque appareil, ou fichier de sauvegarde) : premier écran →
**Autres façons** → « J'ai déjà une boutique : la retrouver ».

## 4. Première journée (10 minutes de pratique, obligatoire)
Avec un vendeur, sur le vrai téléphone :
1. **Ma caisse → Ouvrir la caisse** : compter l'argent du tiroir.
2. **Vendre** : 2 produits → **Encaisser** → le client donne un billet → l'application dit combien rendre →
   **Valider** → **Envoyer le reçu** (WhatsApp).
3. Une **vente à crédit** à un client (Clients → Nouveau client).
4. **Ma caisse → Fermer la caisse** : compter l'argent → l'écart s'affiche au patron.
5. Montrer au patron sa carte **« Aujourd'hui »** (ventes, bénéfice, crédits) et **Chiffres**.

## 5. À distance (appel WhatsApp)
- Demander au patron de passer en **appel vidéo** et de filmer l'écran avec un **autre** téléphone, ou de
  faire des **captures d'écran** à chaque étape.
- Lire les étapes du point 2 **une à une**, attendre « c'est fait » avant la suivante.
- Ne jamais demander le code du patron ni celui d'un vendeur. Le code d'activation, lui, peut être renvoyé.
- Fin d'appel : faire la **liste de vérification** (`5-liste-verification.md`) à voix haute.
