# Assistance WhatsApp — réponses aux questions fréquentes

Ton : poli, phrases courtes. **Ne jamais demander** le code du patron, d'un vendeur, ni un mot de passe.
Demander une **capture d'écran** quand la question n'est pas claire.

| Question du client | Réponse à envoyer |
|---|---|
| « Le téléphone dit qu'il ne peut pas utiliser Zéro Perte » | Ce téléphone n'a pas les services Google (souvent Huawei récent) ou moins de 100 Mo libres. Libérez de la place (photos, vidéos WhatsApp) ou utilisez un autre téléphone Android 8+. |
| « Le code d'activation est refusé » | Copiez tout le message du code (appui long → Copier), puis « Coller le code ». Ne tapez pas le code à la main. Toujours refusé : envoyez une capture, on vous renvoie un code. |
| « J'ai oublié mon code de patron » | Pour votre sécurité, personne ne peut le voir. Si la boutique est sauvegardée sur Google Drive : réinstallez et choisissez « J'ai déjà une boutique : la retrouver ». Sinon, contactez-nous en appel. |
| « Un vendeur a oublié son code » | Patron : Gestion → Vendeurs → le vendeur → **Changer le code** : un nouveau code est tiré au hasard. |
| « Écran bloqué 5 minutes » | 5 codes faux de suite. Attendez 5 minutes. Le patron a reçu une alerte. |
| « Le produit n'est pas dans la liste » | D'abord, dans Vendre, tapez son nom dans « Chercher un produit ». **⚠ Ajouter un produit après l'installation n'est pas encore possible (prévu dans la prochaine version)** : notez-le et prévenez le responsable. |
| « Le prix est faux » | **⚠ Changer un prix après l'installation n'est pas encore possible (prévu dans la prochaine version).** En attendant, à la vente, « Donne pour … F » (vente au montant) si le produit le permet ; prévenir le responsable. |
| « Un client rapporte un produit » | Vendre → **Ventes** (en haut) → la vente → **Retour** : l'argent rendu et le stock sont corrigés. |
| « Je me suis trompé dans une vente » | Ventes du jour → la vente → **Annuler** (motif obligatoire). Le patron est prévenu au-delà de 5 000 F. |
| « Il manque de l'argent à la fermeture » | L'écart est enregistré. Le patron le voit dans Ma caisse → Sessions de caisse. Vérifiez les dépenses et l'argent pris du jour. |
| « Le reçu ne part pas sur WhatsApp » | WhatsApp doit être installé. Sinon, le menu de partage s'ouvre : choisissez une autre application. |
| « Mes ventes n'apparaissent pas sur l'autre téléphone » | Les deux appareils doivent être connectés au même compte Google de la boutique (Gestion → Appareils et Drive) et avoir eu Internet une fois. |
| « J'ai changé de téléphone » | Nouveau téléphone : installez, puis « J'ai déjà une boutique : la retrouver » avec le compte Google de la boutique. |
| « Nouvelle version disponible » | Touchez le message sur l'accueil, installez le fichier. Vos données restent. |
| « L'application est lente » | Fermez-la et rouvrez-la. Toujours lente : envoyez le modèle du téléphone et une capture. |
| « Combien ça coûte / un téléphone de plus ? » | Transmettre au responsable commercial (licence ou extension, voir `4-procedure-codes.md`). |
