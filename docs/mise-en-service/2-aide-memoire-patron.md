# Zéro Perte — aide-mémoire du patron (1 page)

**Chaque matin** — Ma caisse → **Ouvrir la caisse** : comptez l'argent du tiroir.

**Vendre** — Gros bouton vert **Vendre** → touchez les produits → **Encaisser** → Espèces, Flooz, Mixx by Yas
ou Crédit → l'application dit **combien rendre** → **Valider** → **Envoyer le reçu** sur WhatsApp.
Un produit qui n'est pas encore dans la liste ? **Nouveau produit** : son nom et son prix suffisent.
Vendu en gros ? Deux gros boutons : **Détail** (1 boîte) ou **Gros** (1 carton) : le stock se calcule tout seul.

**Ce qu'on me doit** (crédit) — le client → **Il rembourse** quand il paie. Il ne peut pas dépasser le plafond.
**Ce que je dois** — vos dettes chez les fournisseurs.

**Dépense / argent pris** — Ma caisse → **Dépense** (achat payé avec la caisse) ou **Argent pris**.

**Marchandise reçue** — **Arrivage** → le produit → « 10 cartons » : le stock monte tout seul.
**Compter mon stock** — pas besoin de tout compter le premier jour : Gestion → **Compter mon stock** → 5 produits
à la fois, les plus vendus d'abord.
**Produits et prix** — Gestion → **Produits et prix** : ajouter un produit, changer un prix (l'ancien prix
est gardé dans l'historique), masquer un produit qui ne se vend plus.

**Chaque soir** — Ma caisse → **Fermer la caisse** : on compte l'argent **sans voir** le montant attendu.
Vous voyez tout de suite **l'écart** (manque ou surplus). Bouton **Envoyer sur WhatsApp** : le récapitulatif.

**Vos chiffres** — Accueil : **Vendu aujourd'hui**, **Bénéfice**, et **Caisse : juste ✅** ou **il manque … ❌**
(espèces), par vendeur s'il y en a plusieurs. Pas de bénéfice ? Ajoutez le prix d'achat. **Mon bénéfice** →
**Résumé** : semaine, mois, produits qui rapportent, **stock bas** ; **À envoyer** : le rapport en image ou
en Excel.

**Résumé du soir** — Quand un vendeur ferme la caisse, vous voyez le résumé de la journée (ventes, bénéfice,
écart de caisse, stock bas) à l'ouverture de votre application. Bouton **Envoyer sur WhatsApp** pour le
garder ou le partager : rien n'est envoyé sans vous.

**Commander** — Chiffres → Stock bas → **Commander sur WhatsApp** → choisissez le fournisseur : WhatsApp
s'ouvre avec la liste déjà écrite. Ajoutez les quantités, puis envoyez.

**Crédits en retard** — Clients → bandeau **« crédits en retard »** (rien payé depuis 14 jours) →
**Rappeler** : WhatsApp s'ouvre avec le message poli déjà écrit. Vous envoyez.

**Inventaire** — **Inventaire → Compter les produits du jour** (quelques produits chaque jour) : les écarts
montrent ce qui disparaît.

**Ajouter un vendeur avec son téléphone** — Accueil → **Ajouter mon vendeur** → son prénom → Google :
choisissez le compte de la boutique → **Continuer** → un **QR code** s'affiche (10 minutes, une seule fois).
Le vendeur installe Zéro Perte → **Je suis vendeur** → il scanne. Son code à 4 chiffres s'affiche sur
**son** téléphone. Pas d'appareil photo ? Touchez **Pas d'appareil photo ?** et dites **OUI** quand votre
téléphone vous le demande.

**Mes appareils** — Gestion → **Mes appareils** : la liste des téléphones de la boutique (2 par licence).
**Retirer** un téléphone (vendeur parti). Téléphone **volé** : **Couper tous les vendeurs**.

**Vendeurs** — Gestion → **Vendeurs** : bloquer, changer un code, ou ajouter un vendeur qui utilise
**votre** téléphone. Chaque vendeur a **son** code : vous savez qui a vendu quoi.

**Sécurité** — Votre code de **6 chiffres** ne se donne à personne, même pas à l'assistance.
5 codes faux = écran bloqué 5 minutes, et vous êtes prévenu.

**Nouvelle version** — Si l'accueil affiche « Nouvelle version disponible », touchez-le et installez.
