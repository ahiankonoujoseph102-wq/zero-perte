# Zéro Perte — aide-mémoire du patron (1 page)

**Chaque matin** — Ma caisse → **Ouvrir la caisse** : comptez l'argent du tiroir.

**Vendre** — Gros bouton vert **Vendre** → touchez les produits → **Encaisser** → espèces, Flooz, Mixx ou
Crédit → l'application dit **combien rendre** → **Valider** → **Envoyer le reçu** sur WhatsApp.
Un produit introuvable ? Tapez son nom dans **Chercher un produit**.

**Crédit** — Clients → le client → **Il rembourse** quand il paie. Il ne peut pas dépasser le plafond.

**Dépense / argent pris** — Ma caisse → **Dépense** (achat payé avec la caisse) ou **Argent pris**.

**Marchandise reçue** — **Arrivages** → le produit → la quantité : le stock monte tout seul.
*(Ajouter un produit ou changer un prix : arrive dans la prochaine version.)*

**Chaque soir** — Ma caisse → **Fermer la caisse** : on compte l'argent **sans voir** le montant attendu.
Vous voyez tout de suite **l'écart** (manque ou surplus).

**Vos chiffres** — Accueil : carte **Aujourd'hui** (ventes, bénéfice, crédits). **Tableau** : semaine,
mois, produits qui rapportent, **stock bas**. **Rapports** : envoyez le rapport en image ou en Excel.

**Inventaire** — **Inventaire → Compter les produits du jour** (quelques produits chaque jour) : les écarts
montrent ce qui disparaît.

**Vendeurs** — Gestion → **Vendeurs** : ajouter, bloquer, changer un code. Chaque vendeur a **son** code :
vous savez qui a vendu quoi.

**Sécurité** — Votre code de **6 chiffres** ne se donne à personne, même pas à l'assistance.
5 codes faux = écran bloqué 5 minutes, et vous êtes prévenu.

**Nouvelle version** — Si l'accueil affiche « Nouvelle version disponible », touchez-le et installez.

**Aide** — Bouton **Aide** dans l'application, ou WhatsApp : **+228 72 24 02 31** / **+228 79 16 23 90**.
