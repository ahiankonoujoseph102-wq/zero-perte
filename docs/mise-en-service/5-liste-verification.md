# Avant de quitter la boutique — liste de vérification

À cocher avec le patron (sur place ou au téléphone). On ne part pas tant qu'une case reste vide.

- [ ] Application installée sur **chaque** appareil prévu (téléphones, tablette, PC) ; ouverture sans
      bandeau rouge « ESSAI ».
- [ ] Code d'activation accepté ; le nom de la boutique est juste.
- [ ] Les **produits vendus tous les jours** sont présents, avec le **bon prix** (3 prix vérifiés à voix
      haute avec le patron).
- [ ] Le patron sait **ajouter un produit** et **changer un prix** (Gestion → Produits et prix).
- [ ] Le patron a choisi **seul** son code de 6 chiffres et sait l'entrer.
- [ ] **Chaque vendeur** a son code et s'est connecté une fois.
- [ ] Caisse **ouverte** avec le vrai fond de caisse.
- [ ] Une vraie vente faite, la monnaie rendue juste, le **reçu envoyé** sur WhatsApp.
- [ ] Le patron sait **fermer la caisse** et lire l'écart.
- [ ] Le patron voit sa carte **« Aujourd'hui »** et sait ouvrir **Chiffres** (Résumé, À envoyer).
- [ ] Le patron sait **commander** au fournisseur (Chiffres → Stock bas → **Commander sur WhatsApp**) et
      **rappeler un crédit en retard** (Clients → bandeau « crédits en retard » → **Rappeler**).
- [ ] Si plusieurs appareils : **compte Google de la boutique** connecté sur chacun (Gestion → Appareils et
      Drive) ; une vente faite sur l'un apparaît sur l'autre.
- [ ] Le patron a l'**aide-mémoire** et les numéros d'assistance (bouton **Aide**).
- [ ] Date de **rappel** notée (appel J+2 : « tout va bien ? »).
